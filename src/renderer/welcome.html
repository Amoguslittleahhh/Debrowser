A few things that are different

  • Tabs you aren't using go to sleep Debrowser keeps memory for the tabs in front of you. The meter in the toolbar opens the task manager.
  • Private windows go through Tor Ctrl Shift N opens one. Nothing from it is kept, and sites don't see where you are.
  • Everything is a keystroke away Ctrl L for the address bar, Ctrl T for a new tab, Ctrl / for all of them.
